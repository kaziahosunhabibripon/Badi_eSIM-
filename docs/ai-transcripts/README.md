# AI coding transcripts

The assignment requires the complete AI coding transcript or session export for every
AI tool used on this project, because a one-shot AI-generated submission is not
acceptable on its own.

## Tools used

- **Cline** (VS Code extension) - initial project scaffolding.
- **Kilo Code** (VS Code extension) - most of the backend implementation.
- **Claude Code** (this assistant) - review, bug fixes, the real-PostgreSQL test suite,
  seed data, and this documentation.

## What belongs here

The real session exports from each tool above, added as their own files in this folder
(for example `cline-session.md`, `kilo-code-session.md`, `claude-code-session.md`),
exported by the author from each tool's own history/export feature.

**Nothing in this folder is written, edited or summarised by an AI tool on the author's
behalf.** A transcript is only meaningful as evidence if it is the real, unedited record
of what was asked and what the tool did - editing or generating it here would defeat the
whole point of requiring one.

This README is the only file an AI tool has written into this folder; every transcript
file next to it is a direct export added by the author.
